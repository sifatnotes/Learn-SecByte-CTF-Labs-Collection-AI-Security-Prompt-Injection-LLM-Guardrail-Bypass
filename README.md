## Introduction

As artificial intelligence architectures and Large Language Models become deeply integrated into enterprise application ecosystems, securing AI agents against novel adversarial vectors has become critical. Hosted on [Learn SecByte](https://learn.secbyte.org/), this cutting-edge AI security collection provides practical, hands-on technical training for evaluating and hardening modern AI infrastructures.

From crafting adversarial prompts and exploiting direct/indirect prompt injection flaws to extracting sensitive system context, bypassing guardrail filters, orchestrating automated AI reconnaissance, weaponizing LLM vulnerability chains, and hardening model defenses against data exfiltration, these exercises prepare practitioners for next-generation security challenges.

## How to Use the Labs

1. Select a challenge link from the index or category sections above.
2. Read the scenario requirements, system prompt specifications, and target directives on [Learn SecByte](https://learn.secbyte.org/).
3. Deploy AI testing utilities (Python, Garak, PyRIT, Burp Suite, custom prompt crafting scripts) inside an isolated laboratory environment.
4. Craft adversarial prompts, exploit tool integrations, bypass guardrail filters, extract hidden flags/secrets, and document defensive countermeasures.
